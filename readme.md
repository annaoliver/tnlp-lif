# Cross-Species Dendritic Morphology Insights Inspired Biologically Plausible Decision Making

## 📖 Overview
This repository contains the official implementation of the paper:

**"Cross-Species Dendritic Morphology Insights Inspired Biologically Plausible Decision Making"**

We propose a biologically plausible decision-making framework inspired by cross-species dendritic morphology. The model integrates dendritic nonlinearities and structural priors to improve robustness and adaptability in complex environments.
